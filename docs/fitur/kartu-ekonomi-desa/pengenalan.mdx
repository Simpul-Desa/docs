# Pengenalan Kartu Ekonomi Desa

Profil ekonomi lengkap tiap desa tanpa satu pun formulir. Seluruh
desa/kelurahan di provinsi percontohan terdata otomatis: nol kuesioner, nol
beban bagi perangkat desa.

Cakupan wilayahnya ada di [Sumber Data](/docs/sumber-data).
