# Fitur

Sembilan fitur SIMPUL DESA, semuanya di bawah halaman ini. Lima yang pertama
adalah lensa dasbor: berganti lensa tidak berpindah halaman dan tidak mereset
peta. Empat sisanya berdiri di luar rail lensa.

Halaman di bawah menjelaskan konsep tiap fitur — istilahnya, keluarannya, dan
cara angkanya dibaca. Tampilannya di dasbor dibahas di tempat lain: bagian
Fitur di Aplikasi pada sidebar Panduan, satu halaman per fitur.
