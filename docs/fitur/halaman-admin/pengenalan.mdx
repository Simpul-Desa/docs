# Halaman Admin

Halaman pengelola sistem, hanya untuk peran admin. Dari sini penyegaran Berita
Desa dijalankan, berita dihapus, daftar pengguna dibaca, peran pengguna
dinaikkan, dan status sistem dibaca — versi data, cacah isi, dan pekerjaan
latar yang sedang berjalan.

Isi halaman ini masih kerangka. Kontrak tiap operasinya sudah lengkap di
[rujukan REST API](/api/endpoint/administrasi).
