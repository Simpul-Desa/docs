# Sumber pipeline utama

Sembilan sumber di halaman ini mengisi tabel induk — satu baris per wilayah
desa dan kelurahan, dibaca oleh semua model. Kalau sebuah kolom dipakai lebih
dari satu fitur, kolom itu datang dari sini.

| Sumber | Yang diambil |
| --- | --- |
| [SIG BPS](https://sig.bps.go.id) | kerangka 17.467 wilayah dan bridging kode BPS ke kode Kemendagri |
| [GeoServer ST2023 BPS](https://geoserver.bps.go.id/st2023/ows) | poligon batas desa, agregat Sensus Pertanian 2023, landmark pertanian |
| [WebGIS ST2023 BPS](https://webgis-st2023.web.bps.go.id) | kamus nama komoditas per peringkat per provinsi |
| [WMS Tutupan Lahan BPS](https://geoserver.bps.go.id/tutupan_lahan/wms) | dua belas proporsi tutupan lahan resolusi 100 m per desa |
| [OpenTopoData](https://api.opentopodata.org) | elevasi dan relief per desa dari SRTM 90 m |
| [OSRM publik](https://router.project-osrm.org) | waktu tempuh ke pusat kota, bandara, dan pelabuhan, serta matriks waktu tempuh antar desa |
| [Overpass OpenStreetMap](https://overpass-api.de/api/interpreter) | enam hitungan titik minat per desa dan titik acuan tujuan waktu tempuh |
| [IDM Kemendesa](https://idm.kemendesa.go.id) | IKS, IKE, IKL, skor dan status Indeks Desa Membangun 2024 |
| [Jadesta Kemenpar](https://jadesta.kemenpar.go.id) | registri desa wisata beserta kategori verifikasinya; halaman detailnya menjadi bobot varian Wisata |

Cakupan wilayahnya, kunci join antar sumber, dan catatan mutu tiap sumber ada
di [Sumber Data](/docs/sumber-data).
