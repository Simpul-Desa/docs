# Sumber tambahan

Sembilan sumber berikut di luar tabel induk. Fitur tertentu membacanya
langsung, dan penggabungannya selalu dilakukan di hilir.

| Sumber | Yang diambil |
| --- | --- |
| [Sisparnas Kemenpar](https://sisparnas.kemenpar.go.id) | 3.858 titik daya tarik wisata berkoordinat, dihitung per desa |

| [PIPP KKP](https://pipp.kkp.go.id) | 686 pelabuhan perikanan untuk skor perikanan varian Cold Storage |
| [SIPCS KKP](https://sipcs.kkp.go.id) dan [GISHUB Kemenhub](https://gishub.kemenhub.go.id) | titik cold storage versi lain, dipakai sebagai pembanding saja |

di [Sumber Data](/docs/sumber-data).
