# Halaman Admin

Halaman Admin memegang pengelolaan pengguna dan kenaikan peran, pemantauan
status sistem, penyegaran Berita Desa untuk desa terpilih, dan penghapusan
berita.

Halaman ini menunjukkan Halaman Admin **seperti yang terlihat di Portal**.
Penjelasan konsepnya, termasuk istilah dan cara angkanya dihitung, ada di
[halaman Halaman Admin](/docs/fitur/halaman-admin/pengenalan).

<div className="sd-shot" role="img" aria-label="Slot tangkapan layar Halaman Admin, belum diisi">Tangkapan layar menyusul — status sistem dan daftar pengguna</div>

Yang perlu terlihat: versi data, cacah isi, pekerjaan penyegaran yang sedang
berjalan, dan daftar pengguna beserta perannya.

Slotnya masih kosong sampai Portal dan API-nya dijalankan pemilik proyek.
