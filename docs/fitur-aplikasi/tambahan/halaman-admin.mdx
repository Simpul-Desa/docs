# Halaman Admin

**Halaman Admin** adalah pusat kendali dan pengelolaan sistem SIMPUL DESA di rute `/admin` yang dikhususkan secara eksklusif bagi pengguna dengan peran **Admin**.

Fitur ini mencakup 4 modul operasional: manajemen pengguna dan persetujuan kenaikan peran (*role upgrade*), pemantauan kesehatan layanan dan status sistem (*system health*), pemicu penyegaran panen Berita Desa per wilayah, serta moderasi/penghapusan berita.

---

## Tampilan Antarmuka di Portal

Antarmuka Halaman Admin mengadopsi tata letak berbasis tab bar horizontal yang memisahkan modul-modul pengelolaan sistem:

![Tampilan Antarmuka Halaman Admin pada Portal SIMPUL DESA](/screenshoot/pengenalan-hal-admin.png)

* **Tab Pengguna**: Tabel daftar pengguna terdaftar, pencarian akun, dan formulir perubahan peran (Tamu, Pemerintah, Swasta, Admin).
* **Tab Status Sistem**: Pemantauan versi data, ketersediaan koneksi database Supabase, dan layanan API analitik.
* **Tab Berita**: Pemilih desa untuk memicu proses panen (*scraping*) berita baru atau menghapus artikel duplikat.
